# Demo 视频口播与画面安排

与定版 Deck 配合。视频保留安装、生成、计划、执行与反馈的关键操作；下载和执行等待经剪辑。
生成草案来自独立练习目录；后续业务执行使用仓库中已审阅的固定版本。来源与证据说明见 [维护说明](internal/README.md)。

## 01 · 从业务要求走完整条测试流程
画面：Deck 第 1 页 / deck。

用一条业务要求，走完 gherkai 的测试工作流：从需求生成用例与确定性步骤，检查计划并实际运行；随后模拟缺陷，读取失败依据，让人和 agent 据此继续处理，最后恢复应用，在云端完成双引擎验证。

## 02 · 先明确什么才算通过
画面：Deck 第 2 页 / deck。
