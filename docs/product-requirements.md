# 识字大挑战 · 产品需求

> 版本 1.0。本文描述「识字大挑战」课件要做成什么样，是开发与验收的依据。

## 1. 背景与目标

小学二年级上册语文识字量大，学生课后缺少轻量、有趣的复习方式。「识字大挑战」是一个在浏览器里打开就能玩的识字小游戏：看汉字、选拼音、闯关得分。目标是让学生每次花三到五分钟完成一组十个生字的练习，答错时立刻看到正确答案。

## 2. 使用者与使用场景

- 二年级学生：在家或在教室用电脑、平板、手机的浏览器打开，独立完成一组练习。
- 教师与家长：投屏演示，或陪学生一起玩；需要英文界面时（国际学校、双语家庭）可以切换。

## 3. 范围

做：主页、选关、答题、结算四个页面，中英双语界面，答对答错的即时反馈与音效。

不做：登录与账户、学习记录保存、排行榜、后台管理。应用不连接任何服务器，不采集数据。

## 4. 题库

- 题库为统编版二年级上册生字表中的 81 个生字，每个生字对应一个标准拼音（带声调）。
- 题库随应用发布，内嵌在页面里，不从网络加载。

## 5. 页面与流程

主页 → 选关页 → 答题页 → 结算页。结算页可以回到答题页（同一组再玩一次）或主页；选关页可以回到主页。

### F1 主页

- 显示课件标题「识字大挑战」与一个「开始挑战」按钮。
- 点击「开始挑战」进入选关页。
- 页面标题（浏览器标签上显示的文字）为「识字大挑战 - 二年级上册」。

### F2 选关页

- 标题「选择关卡」。
- 显示 8 个关卡按钮，第 N 个按钮标注「第 N 组」与「10 个生字」。
- 每次打开应用时，把 81 个生字随机打乱后每 10 个分为一组，共 8 组；余下的 1 个生字本次不出现。因此同一组在两次打开之间的生字不同。
- 点击某个关卡进入该组的答题页，从第 1 题开始，得分从 0 开始。
- 提供「返回主页」按钮。

### F3 答题页

- 顶部显示当前得分与进度「当前题号 / 10」，另有一条随题号推进的进度条。
- 中央的生字卡显示本题的一个汉字。
- 下方显示 4 个拼音选项：1 个是该字的正确拼音，3 个是从题库其它生字里随机取的干扰项，4 个选项顺序随机。
- 点击正确选项：该选项变为绿色的「答对」状态，得分加 1，播放答对音效。
- 点击错误选项：该选项变为红色的「答错」状态，同时正确选项以绿色高亮提示，得分不变，播放答错音效。
- 一题只能作答一次，作答后再点其它选项无效。
- 作答后自动进入下一题：答对停留 1.5 秒，答错停留 3 秒，让学生看清正确答案。
- 第 10 题作答并停留结束后进入结算页。

### F4 结算页

- 标题「挑战完成！」，显示本组最终得分。
- 评语按得分给出：10 分显示「太厉害了！全对！🌟」；8 分或 9 分显示「真棒！继续加油！✨」；7 分及以下显示「再接再厉哦！💪」。
- 播放结束音效。
- 「再玩一次」按钮：用同一组生字重新开始，得分清零、从第 1 题开始。
- 「返回主页」按钮：回到主页。

### F5 界面语言

- 界面支持中文与英文两种语言。语言只影响界面文案（标题、按钮、关卡名、进度、评语），题目内容（汉字与拼音）不随语言变化。
- 启动语言由地址参数决定：`?lang=en` 为英文，`?lang=zh` 或不带参数为中文。
- 页面右上角有一个语言切换按钮，按钮上显示切换目标语言的名字（中文界面显示「EN」，英文界面显示「中文」）。任何页面都可以切换，切换后立即生效，进行中的答题不受影响（题目、进度、得分保持），并把语言写回地址栏，刷新后保持。
- 英文界面的对应文案：

| 中文 | 英文 |
|---|---|
| 识字大挑战 - 二年级上册（页面标题） | Character Challenge - Grade 2, Volume 1 |
| 识字大挑战 | Character Challenge |
| 开始挑战 | Start Challenge |
| 选择关卡 | Choose a Level |
| 第 N 组 | Group N |
| 10 个生字 | 10 characters |
| 返回主页 | Back to Home |
| 挑战完成！ | Challenge Complete! |
| 再玩一次 | Play Again |
| 太厉害了！全对！🌟 | Amazing! All correct! 🌟 |
| 真棒！继续加油！✨ | Great job! Keep it up! ✨ |
| 再接再厉哦！💪 | Keep trying! 💪 |

### F6 音效

- 四段语音提示：进入选关页时的欢迎语、答对、答错、结算。浏览器不允许自动播放时静默跳过，不影响功能。

## 6. 非功能需求

- 纯前端静态页面，一个 HTML 文件加本地资源，不需要后端，任何静态文件服务都能托管，断网可运行。
- 桌面与移动浏览器均可使用，按钮足够大，适合触屏。
- 页面切换与选项出现带轻量动画，不影响操作。

## 7. 验收要点

- F1 到 F5 的每一条都能在浏览器里逐条核对。
- 中英文两种界面下，F1 到 F4 的行为一致。
- 答对与答错的判定以题库为准：同一个汉字无论出现在哪一组、哪一题，正确拼音相同。
