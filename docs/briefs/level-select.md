# 测试任务简报：选关页

## 功能域与对应需求

选关页。需求 F2「选关页」，文件 `docs/product-requirements.md`；分组规则见同文件 F2 与第 4 节题库。

## 被测地址与界面语言

本机运行 `cd app && python3 -m http.server 8080`，地址 `http://localhost:8080`。界面中文为主；英文界面用 `http://localhost:8080/?lang=en` 启动，英文界面覆盖一条代表性场景即可。

## 要覆盖的场景

1. 冒烟：从主页点击「开始挑战」 → 进入选关页：标题「选择关卡」，显示 8 个关卡按钮，每个按钮标注「第 N 组」与「10 个生字」，页面有「返回主页」按钮。
2. 返回主页：在选关页点击「返回主页」 → 返回主页，页面显示「开始挑战」按钮。
3. 进入关卡：点击「第 3 组」 → 进入答题页，进度显示第 1 题共 10 题，得分 0。
4. 英文界面下的选关页（场景 1 的英文镜像）：标题、8 个按钮的文案、返回按钮都是英文。

## 必须精确的检查

- 关卡按钮恰好 8 个。
- 第 N 个按钮的文案是「第 N 组」与「10 个生字」（英文界面为「Group N」与「10 characters」）。
- 进入关卡后进度「1 / 10」与得分 0。

## 交给 AI 判定的检查

- 选关页整体呈现为可点选的关卡列表。
- 返回主页后，页面呈现主页形态。
- 英文界面下页面文案确实是英文。

无。
